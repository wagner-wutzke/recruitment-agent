## 1. Overview (The Problem)

Provide a web application that helps HR and IT recruiters identify suitable candidates for an open
position.

## 2. Feature Scope

### In Scope

- [ ] Item 1: A new SPA web application is to be developed.
- [ ] Item 2: The application is named "Recruitment Agent" and displays the title "Recruitment made
  easy".
- [ ] Item 3: The web app has a list of Job offers on the left side, loaded from the system
  database.
- [ ] Item 4: The web app has a block on the right side where the selected Job offer details are
  shown.
- [ ] Item 5: The web app design uses dark blue and lilac colors.
- [ ] Item 6: A read-only Job offer record contains the following fields:
  - Identifier: generated by MongoDB.
  - Job Name: text.
  - Job Description: text.
  - Required Qualifications: text.
  - Location: text.
  - Allocation: text.
  The stored field names are `jobName`, `jobDescription`, `requiredQualifications`, `location`,
  and `allocation`; the identifier is exposed as `id` by the application.
- [ ] Item 7: The application shall retrieve Job offer records from the `job_offers` MongoDB
  collection.
  When the collection has no records, the list is empty.

### Out of Scope

- Create, edit and delete Job offers.

## 3. Business Rules

- **BR01** - to be ignored, no business rule yet.

## 4. Acceptance Criteria

- **AC01** - A new SPA web application is to be reached at `http://localhost:8080`.
- **AC02** - If the database contains no Job offers, the SPA shows an empty list in the left-side
  block.
- **AC03** - The SPA has a block on the right side which is empty. It will be filled with the
  selected Job description when an entry is selected on the left side list.
- **AC04** - On load, the SPA retrieves Job offers from the `job_offers` collection and displays
  the returned records in the left-side list; if there are no records, the list is empty.
- **AC05** - Selecting a listed Job offer displays its job name, job description, required
  qualifications, location, and allocation in the right-side details block.
