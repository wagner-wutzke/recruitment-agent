## 1. Objective and Context

Use an AI-powered Retrieval-Augmented Generation (RAG) approach, grounding candidate matching in the
indexed resume data.

## 2. Business Rules

- When searching for a matching candidate, use the Vector Store data to find a suitable candidate.
- Do not use data from the LLM.

## 3. Functional Requirements

- Add a **Find Candidates** button below the Offers panel.
- The button must be aligned horizontally with the Edit and New Job Offer buttons.
- Clicking the button starts the search process.
- When the search process finishes, a new **Search Results** panel is shown in the place of the
  Details panel.
- If no matching results are available, show the proper message to the recruiter.

## 4. Non-Functional Requirements

- Nothing to declare.

## Acceptance Criteria

### Scenario 1: Find candidates for the selected job offer

- **Given** the recruiter has selected a job offer and resumes are indexed in the local Vector Store
- **When** they select **Find Candidates**
- **Then** the system searches the Vector Store using the selected job offer’s description and required qualifications
- **And** candidate information is sourced from the indexed resumes, not generated by an LLM

### Scenario 2: Display matching candidates

- **Given** the candidate search completes successfully with matching candidates
- **When** the results are displayed
- **Then** the Details panel is replaced by a **Search Results** panel
- **And** the panel displays the matching candidates returned by the Vector Store

### Scenario 3: Display no-match results

- **Given** the recruiter has selected a job offer
- **When** the Vector Store search completes without matching candidates
- **Then** the Details panel is replaced by a **Search Results** panel
- **And** the panel indicates that no matching candidates were found

### Scenario 4: Handle a search failure

- **Given** the local Vector Store is unavailable or the search fails
- **When** the recruiter selects **Find Candidates**
- **Then** a visible search error is shown
- **And** the application does not present the search as successful

### Scenario 5: Require a selected job offer

- **Given** no job offer is selected
- **When** the recruiter views the job-offer page
- **Then** **Find Candidates** is unavailable
- **And** no candidate search is started
